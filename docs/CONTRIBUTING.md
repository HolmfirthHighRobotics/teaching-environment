# How to contribute
## If you are a member of Holmfirth High Robotics
Log into the account and edit it from there.

## If you are NOT a member of Holmfirth High Robotics
Create a fork and make edits, then submit a merge request.
Only edit files that are not ".java", as they are from the students and their practising.
Everything else can be edited at your own jurisdiction, but make sure that code submitted works before submitting a request. If not, your request will be denied.
